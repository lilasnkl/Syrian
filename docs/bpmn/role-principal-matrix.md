# Role and Principal Matrix

| Role/principal | Type | Responsibilities | Permissions/access | BPMN placement | Source evidence | Related BPMN tasks |
|---|---|---|---|---|---|---|
| Customer | Human, authenticated role | Create orders, review offers, chat, complain, review completed orders, ask provider Q&A | `customer`; must be active for protected writes | Customer pool | `docs/01_SYSTEM_OVERVIEW.md`, `backend/apps/orders/services/order_service.py`, `backend/apps/reviews/services/review_service.py`, `backend/apps/customer_assistant/services/assistant_question_service.py` | `Task_CustomerSubmitRequest`, `Task_CustomerReviewOffers`, `Task_CustomerCreateReview`, `Task_RagValidateQuestion` |
| Provider | Human, authenticated role | Maintain provider profile, submit verification, manage services/knowledge, bid, perform work | `provider`; owner-only service/bid/knowledge mutations; active account required | Provider pool | `backend/apps/providers/services/provider_service.py`, `backend/apps/services/services/service_service.py`, `backend/apps/bids/services/bid_service.py`, `backend/apps/knowledge/services/source_submission_service.py` | `Task_ProviderSubmitVerification`, `Task_ProviderManageProfileServices`, `Task_ProviderSubmitBid`, `Task_KnowledgeValidateUpload` |
| Admin | Human privileged role | Verification review, complaint response, dashboard monitoring, account status updates | `admin`; admin/moderator-only queues and decisions | Admin/Moderator pool | `backend/apps/providers/services/provider_service.py`, `backend/apps/complaints/services/complaint_service.py`, `backend/apps/accounts/services/user_service.py`, `backend/apps/admin_panel/api/views.py` | `Task_AdminReviewVerification`, `Task_AdminHandleComplaint`, `Task_AdminModerateAccount`, `Task_AdminViewDashboard` |
| Moderator | Human privileged role | Same operational moderation paths as admin in backend services | `moderator`; backend treats with admin for moderation, frontend maps moderator to admin | Admin/Moderator pool | `backend/shared/constants/roles.py`, `frontend/src/features/auth/role.ts`, `backend/shared/permissions/base.py` | `Task_AdminReviewVerification`, `Task_ComplaintAdminRespond` |
| Anonymous user | Security principal | Browse public providers/services, register/login, request public recommendations | Public endpoints only | Customer pool before sign-in | `backend/apps/providers/api/views.py`, `backend/apps/services/api/views.py`, `backend/apps/recommendations/api/views.py` | `Task_CustomerDiscover` |
| Authenticated active user | Security principal | Access protected routes and APIs according to role | JWT cookie auth, active status check | Platform auth lane | `backend/apps/accounts/api/authentication.py`, `backend/shared/permissions/base.py`, `frontend/src/components/RouteGuards.tsx` | `Sub_Auth`, `Gateway_PlatformAuth` |
| React Frontend | Internal system | Route screens, enforce client guards, call API adapters | Browser app using API base URL | Platform frontend lane | `frontend/src/routes/route-config.tsx`, `frontend/src/api/endpoints.ts` | `Task_PlatformRouteFrontend` |
| Django DRF API | Internal system | Validate requests, return response envelope, dispatch services | Backend API under `/api/v1` | Platform API/auth lane | `backend/config/urls.py`, `docs/08_API_GUIDELINES.md` | `Sub_Auth`, `Sub_OrderSubmission`, `Sub_BidWorkflow` |
| Domain service layer | Internal system | Enforce business rules and state transitions | Service methods and transactions | Platform domain lane | `backend/apps/*/services/*.py`, `docs/02_ARCHITECTURE.md` | All platform subprocesses |
| Database | Internal data store | Persist marketplace entities and histories | Django ORM | Data lane | `backend/apps/*/models/*.py`, `docs/09_DATABASE_GUIDELINES.md` | Data objects and `Store_Postgres` |
| Media file storage | Internal data store | Store verification and knowledge uploads | Django default storage/media | Data lane | `backend/apps/providers/services/provider_service.py`, `backend/apps/knowledge/services/source_submission_service.py` | `Task_ProviderStoreVerification`, `Task_KnowledgeStoreSource` |
| Notification service | Internal system | Create in-app notifications and role-filtered visibility | Recipient-scoped notification rows | Worker lane | `backend/apps/notifications/services/notification_service.py` | `Sub_NotificationsAudit`, `Task_NotifyCreate` |
| Knowledge ingestion worker | Internal system account/process | Process queued extraction, chunking, embeddings, activation | Management command or process-now path | Worker/domain lanes | `backend/apps/knowledge/management/commands/process_knowledge_jobs.py`, `backend/apps/knowledge/services/ingestion_service.py` | `Task_KnowledgeExtractText`, `Task_KnowledgeEmbedChunks` |
| Local Ollama service | External/local AI service | Analyze customer problem descriptions for recommendation | HTTP call to configured Ollama URL | Ollama pool | `backend/apps/recommendations/services/recommendation_analysis.py` | `Task_OllamaAnalyze`, `Task_DiscoveryAnalyzeProblem` |
| OpenAI APIs | External AI service | Create embeddings and structured RAG answers | Server-side SDK using `OPENAI_API_KEY` | OpenAI pool | `backend/apps/knowledge/clients/openai_embedding_client.py`, `backend/apps/customer_assistant/clients/openai_responses_client.py` | `Task_OpenAIEmbed`, `Task_OpenAIGenerate` |
| Zvec vector index | Internal/optional vector backend | Fast provider-scoped candidate retrieval with Postgres refetch | Optional backend with fallback | Data lane | `backend/apps/knowledge/services/vector_backends/factory.py`, `backend/apps/knowledge/tests/test_knowledge_api.py` | `Task_KnowledgeActivateChunks`, `Task_RagRetrieveEvidence` |
